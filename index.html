Project 1: Let's Get Crafty

Project Details

Concept

To create an easily accessible repository for craft inspirations, project instructions, and necessary materials.

Process

  • Plan the structure and content using a wireframe.
  • Create the starter html and css files and assets folder.
  • Input header, nav, main, table, and footer elements into the index.html.
  • Create html pages for yarn, clay, paint, and contact.
  • Link nav content to their respective pages
  • Create a gallery of images and related tutorial links
  • Build a table with links to project details and links to their respective pages.
  • Insert email and buttons in the footer
  • On yarn.html, modify the structure and insert images and descriptions
  • Insert a video at the top of the page with an intro
  • Repeat the new structure across the remaining nav pages.
  • Build a form to receive emails on the contact page.
  • Style the gallery in a grid format.
  • Style the yarn, clay, and paint elements to alternate sides.

Sources

YouTube.com, TinaYu.com, Pinterest.com, Pixabay.com, Flaticon.com and Flickr.com were used to gather inspiration and resources for the project.

Project 2: Pop! A Balloon Popping Game

Project Details

Concept

Utilize Copilot's AI to create an easy to use, engaging carnival-themed water balloon popping game with endless levels and a competitive edge that is geared towards college students. It supports Charity: Water in their mission to provide clean drinking water around the world.

Process

  • Design the layout and mechanics with figma.
  • Create the starter html, css, and js files.
  • Created simple html structure with title and game elements like items and buttons
  • Instructed copilot to create js mechanics, including balloon popping, store, score counter, and water/poison health bar.
  • Styled the game in a whimsical, bright carnival theme
  • Created a more fluid popping animation for the balloons and added prizes and penalties.
  • Created modals for the start and tutorial
  • Test the game and ensure win/lose works

Sources

ASU's Global Career Accelerator, Charity: Water, and Charity:Water color palette

Project 3: Blender Scene: Falling Apple

Project Details

Concept

To explore blender techniques by creating a simple, engaging introductory scene for a cheerful, southern-style, animated story.

Process

  • Create a plane and add material and particle properties to make it green and hair-like.
  • Build a tree trunk and add material properties to add color, noise, and texture.
  • Create a multi-faceted round shape and add color. Duplicate and resize the shape several times, placing them bunched around the tree branches to make leaves.
  • Download an apple asset and resize and duplicate it, adding them sporadically throughout the leaves.
  • Group the tree elements together.
  • Create a single apple and animate its descent from the tree and roll along the ground.
  • Track the apple's movement with the camera.
  • Download a cloudy sky to act as the backdrop of the scene.
  • Render the scene and export it as a video file.

Sources

BlenderKit assets - low poly red apple by Matheus Godoi, Cloudy Sky by Nathan S***** were used to create the scene.
